# Spatial Bench

[Spatial Bench](https://verse.ctruh.com/bench) runs four tests in a real Verse viewer on **your own
device** and gives one score, the Verse Spatial Score. It takes about a minute and a half and you can
cancel at any point.

| Test | What it does |
| --- | --- |
| Product open | Opens a product scene and measures how quickly it opens. |
| Interior walk | Walks a fixed route through a furnished interior. |
| Large exterior | Streams a large outdoor scene along a fixed route. |
| Stress | The same scene at four times the pixels. |

## Why you can trust the numbers

- Every number comes from the engine's own counters or a clock on the page, not an estimate.
- The routes are fixed (same seed, same path), so two runs on the same device are comparable.
- The score formula and its reference points are printed on the page.

## Sharing a result

**Share** creates a link with the numbers and the GPU and browser names only. It carries no name,
address or account. You can also opt in to a leaderboard grouped by device class; partial runs,
repeat runs and outliers are skipped.

## Tips

- Close other tabs, plug a laptop in, and run it twice: the first run warms the caches.
- A phone on battery saver will score lower. That is a true result for that phone in that state.
- If the page says the bench scenes are "not set up yet", the server you opened has not enabled them; use verse.ctruh.com.
