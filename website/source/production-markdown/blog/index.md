# Verse Engine blog

Plain-language posts about what Verse Engine does, how it does it, and
what each release means for the people who use it. New posts are added
here and linked from the product page.

## Posts

  Lighting, BIM files, phone AR and voice tours, explained without the
  jargon. What each new feature means for a client visit.
- **[How Verse streams a 3-million-triangle building into your browser in seconds](how-verse-streams-a-building.md)** — 2026-10-01.
  The problem with 3D files, the streaming idea borrowed from video, the
  measurements, what is new in 2.0 and what comes next. Written for
  everyone.
- **[Verse Engine 2.0 — release notes for humans](2-0-release-notes-for-humans.md)** — 2026-10-01.
  What you can do now, what changed if you were already using Verse, and
  what is still beta. The short version of the changelog.

## Writing for this blog

Posts are Markdown files in `docs/blog/`, rendered by the docs site at
`/docs/#/blog/<file-name>`. Add the post here and to the sidebar list in
`web/playground/docs/index.html` (title, date and a one-sentence
description — the description becomes the page's search snippet and social
card). Diagrams are inline SVG in a ```` ```svg ```` fence. Keep the
language plain: if a sentence needs a glossary, link the
[concepts page](../concepts.md) instead of explaining the internals.
