# How we measure

The four numbers on the home page, and what each one means. Each is measured on a real scene, stated with the
device and connection it applies to, and checked against the figure recorded for it before a page may print it.

## Giant scene

**1.8 billion triangles, on desktop.** A real production scene (a city) is compiled once into a Verse scene and
opened from a link in a desktop browser. The count is the number of triangles in the compiled scene (1,805,458,557).
Verse streams only what the camera can see, so the browser never loads all of it. The number is never claimed for
phones. You can try the scene yourself in the [Verse Challenge](/challenge).

## First picture

**0.9 s to first picture.** For a detailed interior (a barbershop scene), the time from opening the link to the first
picture on screen, over the internet. The scene then sharpens wherever you look. The first picture is a coarse view
of the whole scene, not a loading screen.

## Project to link

**45 s from Blender, 70 s from Unreal, 101 s from Unity.** The time from pressing Publish in the plug-in to a shareable
link, for the same sample project in each tool. It includes preparing the scene and uploading it. Larger projects take
longer; see [Publish from Blender](#/guides/publish-from-blender).

## Phone

**29 s on a phone.** For a large interior on a phone on a typical 4G connection, the time until the scene looks
complete, with no app installed.

## Run it yourself

The method and the raw numbers behind a comparison with other web 3D viewers are published in
[Spatial Bench](#/guides/spatial-bench), so anyone can rerun them. The numbers on the site are held to a recorded
source by an automated check: a page cannot print a figure that differs from it.
